ANN-Based Bearing Fault Classification

Domain
Condition monitoring and ML
Year
2025
Team
Individual project
Course
ME-404 Artificial Intelligence for Mechanical Engineers

Summary

What

Binary healthy or faulty bearing classifier built in Keras from nine statistical vibration features of a Kaggle dataset derived from the Case Western Reserve University bearing set.

Role

Scaled and split a Case Western-derived vibration dataset, trained a 16-8-1 Keras network and evaluated it with a confusion matrix and loss curves, as sole author.

Results

  1. Test accuracy of 99.13 percent on 460 samples, with 2 false positives and 2 false negatives.
  2. Nine input features, including RMS, kurtosis and crest factor, feed hidden layers of 16 and 8 neurons.
  3. Training and validation loss stay close, which the report reads as little overfitting.

Problem

Classify rolling bearing condition as healthy or faulty from numerical features extracted from vibration signals, as a supervised binary classification problem.

Method

  1. Dataset: Kaggle data derived from the Case Western Reserve University bearing set, with nine features: maximum, minimum, mean, standard deviation, RMS, skewness, kurtosis, crest factor and form factor.
  2. Labels encoded as 0 for healthy and 1 for faulty, with an 80:20 train-test split and StandardScaler applied.
  3. Keras Sequential network: 9 inputs, hidden layers of 16 and 8 neurons with ReLU, one sigmoid output and a threshold of 0.5.
  4. Adam optimizer, binary cross-entropy loss, 50 epochs, batch size 32 and a validation split.
  5. Evaluation by accuracy, confusion matrix and loss curves.

Equations

  1. EQ. 1z = w1 x1 + w2 x2 + ... + wn xn + b
  2. EQ. 2ReLU(z) = max(0, z)
  3. EQ. 3y_hat = 1 / (1 + e^(-z))
  4. EQ. 4L = -[y log(y_hat) + (1 - y) log(1 - y_hat)]
  5. EQ. 5dL/dw = (dL/dy_hat)(dy_hat/dz)(dz/dw)
  6. EQ. 6w_new = w_old - alpha (dL/dw)

Results

Test accuracy is 99.13 percent: 4 misclassifications out of 460 test samples, 2 false positives and 2 false negatives. Training and validation loss curves fall smoothly and stay close.

Validation

A held-out 20 percent test set was evaluated with a confusion matrix and loss curves.

Limitations

  • The data comes from a public set derived from a benchmark, and the author did not collect it.
  • Binary healthy or faulty output only, with no fault type or severity.
  • Single train-test split, no cross-validation, and the report does not say how samples were grouped between the sets.

Tools

  • TensorFlow
  • Keras
  • Pandas
